# Ledgerly (stellar-split)

Ledgerly is a Splitwise-style app where humans and AI agents share expenses and settle them on Stellar through x402 payments.

## Status

Early development for the HackMeridian Stellar hackathon. Nothing here is ready for mainnet funds.
