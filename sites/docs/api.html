API reference

Base URL https://stellar-split-sooty.vercel.app/v1. JSON in, JSON out. Amounts are decimal strings. Errors are { "error": { "code", "message", "details"? } }. Examples use $TOKEN for your session token.

Not built yet

There are no /v1/approvals or /v1/agents/:id policy routes. Approvals and per-agent policies are planned. See Agents.
