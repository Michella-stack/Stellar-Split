25 October 2026

Highlights

  • Agents can be linked to a person with a signed message and pay that person's debts within the caps.
  • The MCP server gained ledgerly_settle, which pays a reserved intent from the agent's own Testnet account.
  • Groups can settle in USDC or EURC, one asset per group.
  • Agent spend caps are enforced on the server: 25 per payment, 50 per day, 200 per 30 days.
  • Settlement intents tie every payment to one reserved debt.
  • Receipt photos can prefill an expense (demo).
  • The MCP server ships as a Docker image with a one-agent Compose example.
  • The web app speaks English, Spanish and Portuguese.
