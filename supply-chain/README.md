# Supply-chain controls

This directory is reserved for Ledgerly's approved-version policy, version guard, action pinning checks, vulnerability exemptions, release verification key, Scorecard threshold check, and tests.

Controls must be read from the pull request's base branch in CI so a change cannot weaken the policy that reviews it. Exemptions require an owner, rationale, and expiry date. Do not add placeholder package versions or action SHAs.
